# 📩 Spam SMS Detection

## 🚀 Overview
Classifies SMS messages as spam or legitimate using NLP.

## 🧠 Approach
- TF-IDF vectorization
- Naive Bayes classifier

## 📊 Results
- Accuracy: 97%

## 📂 Dataset
Download from:
https://www.kaggle.com/datasets

Place `spam.csv` in project folder before running.

## ▶️ Run
python spam.py
